# 电影叙事 · 连续分镜标准 v1.0.0

模板标识：`continuous-cinema`。这是分镜输出格式，与角色资产提取的三套人物版式独立。

## 必须遵守的规则

- 一次分镜生成请求完成内容与格式输出，不为排版再调用模型。
- 剧情依据当前选择的正文或画面剧本；原文对白、旁白不增删、不改写、不重复朗读。
- 资产正式绑定与正文 @ 引用分开处理。仅实际存在、已绑定且有可用参考素材的角色、群像、动物、场景、道具使用真实素材引用；其余写名字，不输出虚构 ID、svg 占位符或裸露的内部编号。
- 按本镜实际画面选择资产；旁白提及不算人物出场，不将全部项目资产塞进每镜。
- 开头介绍素材名称；正文与空间图中的有效素材使用同一个引用。无参考图的名字保持普通文字，不伪装成图片。
- 每个 Seq 为不超过15秒的连续段落，可包含多个镜头。镜头时长按台词、动作和停顿合理估计，不倍速硬塞。
- 每个 Seq 的镜头重新从1计数，累计时长也从0开始；累计值必须与镜头时长一致。
- 🎥、💡、🎭、💬、🔊、🧍、⚖️、🧬、🔗及框线箭头仅用于阅读，不成为画面中的字幕、界面或水印。
- 继承项目画风，不硬编码真人、3D、古代或现代，不借用格式示例的人物、身份、剧情、台词或时长。
- 无效或缺失引用降级为可识别的名称；不能确定名称时提示检查，不展示技术 ID。

【角色固定音色锁】：仅填写本段实际发声角色的声音设定；旁白标明画外音，人物不对口型。

【关键点前缀】：项目画风、时代、媒介、材质、光线、镜头基调。

【全局执行规则】：角色一致性、群像差异、自然微动作和时代连续性。

【画面约束（按需靶向约束）】：当前镜头实际风险，不堆无关禁令。

【特殊触发状态】：按剧情填写，无则写无。

【上段继承状态锁】：位置、朝向、站坐骑乘、持物手、光源、风向和动作承接，无前段则写无。

【场景、空间站位、体态死锁与按需激活模块总设计】：
- 🧍 空间坐标、体态、人物朝向和前后景。
- ⚖️ 180度轴线、机位与遮挡控制。
- 💡 光源、动态投影与环境媒介。

【场景九宫格】：按当前场景列出方位、人物、道具、环境。

【BGM与跨Seq音频DNA无缝锁总设计】：按剧情需要说明音乐、环境底噪、对白闪避和段间承接。用户明确要求无BGM时以其要求为准。

## 版本与扩展
