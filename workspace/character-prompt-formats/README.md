# 角色提示词格式扩展（1.3.13）

> 当前行为与安全安装入口先看 [当前安装与修复说明](./当前安装与修复说明.md)。下文保留历史记录，旧安装脚本不能直接代表当前完整组合；全功能验收尚未完成。

在“提取章节角色、场景与道具”弹窗新增三套格式：原版、正面/侧面/大头照、单侧面。两套新格式采用用户提供的排版结构，但姓名、时代、身份、五官和画风均由实际项目与正文决定。

## 一次模型调用

原版继续走当前启用的 `chapter_assets_extract` 模板。新格式在提交同一个提取请求之前，将固定提取规则与所选角色排版组合为一份完整提示词，直接返回原有 `characters / scenes / props` JSON 合同；不执行第二次模型请求，不修改场景与道具规则。只移除原模板的“人物排版”段，避免原五视图与新格式冲突。固定规则来自安装时本机数据库当前启用的模板，快照在 `src/character-extraction-rules.js`。

角色输出内容仍写入 `multiViewPrompt`，场景、道具仍写入 `prompt`；新增格式信息随角色候选详情保存。刷新恢复任务使用任务中保存的格式快照，不使用之后切换的格式。

## 使用与保存

1. 保存现有工作，重新打开桌面软件，或刷新已打开页面。
2. 进入章节，点击“提取角色、场景与道具”。
3. 在“角色提示词格式”选择三套版本之一。
4. 展开“编辑格式 / 导入导出”，可编辑两套新增格式、保存版本或导入导出 JSON。原版锁定。
5. 点击“开始提取”，同一次模型响应中完成提取和排版。

格式选项与编辑内容保存在桌面当前网页配置的 localStorage，键为 `yingce.character-prompt-formats.v1`。可导出备份；它们没有写入 `prompt_templates` 表，也不会自动同步 GitHub。可导入项目中的 `角色提示词格式.json` 恢复内置模板。

## 文件与安装

- `src/character-prompt-formats.js`：三套默认格式、编辑组件、请求组合与结果标记。
- `src/character-extraction-rules.js`：安装时固定提取规则快照，不包含数据库、密钥或个人项目。
- `install.py`：严格校验补丁位置，仅支持 1.3.13 指定模块，安装前保存原文件。
- `backups/chapters-CeKTBaiU.original.js`：原模块备份。
- `build/`：构建结果与校验信息。

安装：`python install.py`。回退：`python install.py --restore`。只构建：`python install.py --build-only`。
