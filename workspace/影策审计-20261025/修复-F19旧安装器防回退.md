# F19 旧安装器防回退

新增`character-prompt-formats/_audit_install_guard.py`，18个旧`install*.py`只注入两行guard，在docstring和`__future__`之后、其它业务代码之前；统一`install-audit-repairs.py`明确排除。

根代理生成安装目录哨兵：`assets/audit-repairs-marker.json`，建议记录审查bundle manifest绝对路径、哈希和安装时间。**本子任务未写生产哨兵、未安装任何模块。**

存在哨兵时拒绝旧安装和旧restore。仅`install.py --build-only`精确模式允许，因为只有该脚本原来实现无安装构建；其它顶层旧脚本可能忽略参数仍执行生产写入，不能因传入同名flag就放行。异常提示指向统一安装器，需要新基线与明确文件清单。marker即使JSON损坏也按存在保护，不静默绕过。

测试`python -B -m unittest discover -s character-prompt-formats/tests -p test_audit_install_guard.py -v`，5/5通过。含18个真实旧脚本×install/restore共36次隔离子进程，fake LOCALAPPDATA下检测marker就拒绝，临时目录前后逐字不变。没有向子进程传生产安装目录。测试同时AST核对所有旧脚本的guard顺序与Python语法，确认统一安装器无guard。

此guard仅约束调用它的本地脚本。官方升级、其它聊天手动复制、外部安装工具和不调用guard的新脚本不受控制，无法保证官方升级保留本轮修改；仍需统一安装清单、版本/哈希复核与升级后再验收。不得宣称此项修复能阻止任何形式的覆盖。
