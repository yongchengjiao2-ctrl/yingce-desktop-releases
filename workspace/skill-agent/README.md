# 影策 1.3.19 · Skill 对话、章节 Agent 与项目迁移

本模块沿用桌面应用的技能库、模型选择器、生成任务、项目 API 和按账号隔离的本地存储。

## 使用

### 已确认资料库（第一阶段）

Agent 输入区提供「资料库」「本轮上下文」和「带入最近回复」。人物、设定、总纲、集纲和创作规则可手工录入，也可在成功回复下点击「确认采用」，删去讨论和备选方案后再确认。资料按账号和项目隔离，同项目会话共用；每次修改保留旧版本，可取消后续带入。章节保存仅是存稿，不会自动确认。

请求改为已启用的项目资料＋手动引用＋可选的最近一份未确认工作稿＋本轮要求，不再自动发送全部聊天。上下文预览展示组装内容，技能指令仍由原技能流程另行加载；每条回复记录所用资料版本。资料库在本机 scoped localforage 保存，项目 ZIP 包含本项目资料及版本，导入后映射到新项目。第一阶段由用户决定哪些资料带入，尚未实现按出场人物自动检索、每集剧情状态或钩子关联。

测试：`node --test tests/*.test.js` 与 `python -m unittest discover -s tests -p test_project_bundle.py`。本功能当前以源码与已安装文件修补交付，原 1.3.19 ZIP 尚未重打包。

- 创作页直接选择 Skill，保留原生聊天流程。章节页右上角提供唯一的 Agent 入口；项目列表、概览和其他工作区不显示助手。
- Agent 支持拖动、放大、还原、全屏与最小化。更多和历史使用与窗口对齐的下拉菜单，背景保持清晰。图标提供悬停说明；对话标题可点击改名。
- 选择模型、技能和参考内容后发送。可引用当前选区、当前章节、指定章节、人物/场景/道具设定、大纲、本地文字资料及历史消息。
- 空闲输入框收起，悬停或聚焦展开；发送和停止在右侧。发送时保留阅读位置，重新打开定位最近回复开头。
- 回复使用原生头像、状态和 Markdown 排版。可复制、下载、直接保存到新章节或追加已有章节；预览可选，保存保留标题、加粗、编号列表和引用。写入记录保留来源及原文。
- 历史会话点击即可继续，右侧可引用选定消息或删除。删除留有本地恢复记录，防止旧后台保存将删除项重新写回。
- 项目卡片的删除按钮左侧提供一键打包，按所选项目导出 ZIP。旁边的上传卡片可导入 ZIP 并创建副本；管理员后台另有目录和源文件管理入口。

## 迁移包

包含章节富文本、关联的 Agent/创作聊天、画布及画布聊天、人物资产、镜头、工作流、引用的本地资源和 Skill 包。仅选择所选项目及其关联记录，不复制账号、模型渠道密钥或整个浏览器配置。

导出使用 SQLite 一致性快照；素材缺失或非本地时阻止生成不完整 ZIP。导入检查版本、路径、结构和 SHA256，重新映射标识及资源路径，导入前备份并使用事务写入，不覆盖已有项目。未完成生成任务不会自动恢复执行。前端聊天导入有持久化回执，异常中断后可恢复。

新电脑需安装 v1.3.19，并自行配置模型接口和 API Key。默认导出目录是安装目录下的 `exports/project-bundles`。

## 验证与发行

- `node --test tests/*.test.js`：17 项前端及交互检查。
- `python -m unittest discover -s tests -p 'test_*.py'`：7 项迁移及长路径安装检查。
- `python acceptance.py --round N`：独立账号与目录的实际后端验收；`--runtime-root` 可指向完整 ZIP 新安装的运行目录。
- `python build-release.py --stage` 与 `--archive`：从已安装基线捕获运行模块，叠加可审阅补丁、计算文件清单并生成发行 ZIP。发行包不采集个人数据目录。
- `portable-install.py` 使用随包 Python 处理中文、空格和 Windows 长路径，校验文件后安装。无需系统预装 Python 或 Node。

修改已安装桌面：运行 `python install.py` 与 `python install-bundles.py`。运行中的桌面文件被锁定时暂存更新，关闭后通过安装根目录的启动命令应用。发行包内已直接安装全部模块，不需要用户运行这些开发脚本。

## 已知边界

助手窗口恢复已修复：旧保存状态出现 `144×1` 等异常尺寸时恢复为可见窗口；最小化或过小视口不再写入异常尺寸，窗口过小或移出视口时保留恢复入口。测试覆盖无效尺寸、临时小视口、重新打开及完整对话流程；安装版脚本在隔离浏览器中验证异常保存状态恢复。刷新页面后生效，不删除会话或正式资料。

重新生成会在技能准备成功后移除所点击的旧助手回复，保留原用户提问、其他回复及引用，并持久化替换结果；技能准备失败保留原记录。生成期间输入框也支持移开鼠标后收起，收起状态保留可用的停止按钮。测试：`node --test tests/retry.test.js tests/composer.test.js`。

源码已修复空正文终态与章节清空崩溃：停止的空回复显示“已停止，尚未收到正文”，清空章节后自动创建并选中“1”。现有 1.3.19 完整 ZIP 尚未包含此修复，维护者可运行 `python chapter_state_patch.py --install-root <安装目录>` 更新已安装版本；脚本先备份文件，并校验目标构建的替换位置。专项测试为 `node --test tests/message-state.test.js` 和 `python -m unittest discover -s tests -p test_chapter_state.py`。

模型调用依赖用户自己的有效渠道、协议和密钥；验收不调用收费模型。Skill 加载指令和可解析引用文件，不执行包内任意本地脚本。聊天记录保留供回看与手动引用，本轮默认仅携带资料库、引用和可选最近工作稿。若本轮资料自身超出安全预算则明确报错，不截断正文。章节正文写入采用写前回读和写后校验，后端暂不提供 sourceText 原子版本比较。自动验收在独立 Windows 目录模拟新电脑环境，不代表已覆盖所有硬件及第三方服务组合。
